收起规则
  1. 二级栏属于页面内容，不是第二条侧栏。成绩、教学、管理三个入口共用一个组件，结构抄 ConversationSidebar。
  2. 窗口 ≥ 1280：默认展开，停靠在侧栏右边；标题右侧 32×32 按钮收起，宽度 240 → 0。
  3. 收起后内容区顶部出现 48px 面包屑条：展开按钮 + 「管理 › 总览」+ 当前范围，防止丢失位置。
  4. 窗口 < 1280（含桌面最小 1100×720）：默认收起；展开时浮在内容区上方，带 40% 遮罩，点遮罩或选中一项后自动收起。复用 .conversation-sidebar.is-floating 与 overlay。
  5. 收起状态按入口记在本地，属于界面偏好，不跟账号同步。动画 width / transform 250ms ease，与现有一致。
