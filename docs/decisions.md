## 规划时定下的技术做法（可随实现调整，变化时更新这里）

- 2026-11-03 用户确认：后端架构参考 `deepfate-server`；数据库用 PostgreSQL；后续要接 Prometheus。据此：Go 标准库 `net/http` + `pgx/v5` + 嵌入式 SQL 迁移，PostgreSQL（版本见下文），`prometheus/client_golang` 独立指标端口，契约以 `api/openapi.json` 为准，部署和工作约定同 deepfate（见 plan/02-backend.md）。
- 管理页面由前端带访问令牌直接调 Go API；本机 Python 只做开实训目录、采集作品这类本机操作，不持有平台令牌。
- 智能体只拿模型令牌，只能调模型网关。
- 所有模型用量记在一张 `usage_ledger` 表里，预算、额度、计量都读它。
- 不迁共享密码、免登录演示、`X-Demo-Role` 请求头和四个「核对」面板，改用事务和幂等键。
